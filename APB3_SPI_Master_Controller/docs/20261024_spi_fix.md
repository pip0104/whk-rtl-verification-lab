# SPI 活动帧分频修复与定向回归（2026-10-24）

本报告对应独立作品集副本的实际执行结果。没有修改原项目或原 ZIP。

## 缺陷与修复

规格 `spi_master_spec.md` 第 47 行规定：帧内写 CTRL/CLKDIV 不改变当前输出波形。旧 RTL 虽然锁存模式、位序、帧长，但活动计数器直接比较软件寄存器 `clkdiv_reg`。

因此，BUSY 时写更大的 CLKDIV 会延长当前帧半周期；写小于当前计数值的 CLKDIV 可能使计数器越过比较点，等待 16 位计数回绕。本次公开接口测试实际复现的是“应出现的 SCLK 边沿未按启动时分频到达”，没有等待完整回绕并测量 65536 拍。

最小修复增加 16 位 `clkdiv_latched`：异步复位清零；仅在合法 START 消费 TXDATA 时从 `clkdiv_reg` 锁存；活动分频比较改用该锁存值。软件读写 CLKDIV 的行为保留，更新值在下一帧 START 生效。复位和清 ENABLE 的 abort 语义没有修改。RTL 末尾还增加 `FORMAL` 条件 include，仅供形式验证使用，普通仿真和综合不启用。

## 新增的 24 个定向用例

测试文件：`tests/cocotb/test_spi_deepening.py`。所有检查仅通过 APB、PCLK、SPI 引脚完成，不读取 DUT 内部锁存器来判断结果。

- 8 个活动分频用例：四种 SPI 模式 × CLKDIV 增大（1→7）/减小（7→0）。在首个 SPI 边沿后进行 APB 写，检查当前帧每个半周期、完整 16 个边沿、MOSI/RXDATA；随后不重写 divider 再启动下一帧，检查新的分频确实生效。
- 16 个边界用例：四种模式 × 帧宽 1/32 × MSB/LSB，全部采用 divider=0。检查首沿间隔、每个半周期、恰好 2×帧宽 个边沿、最终 SCLK 回 CPOL、CS 释放、MOSI/RXDATA 和空闲状态。

这些是额外的独立定向测试，没有把原有 23/23 事务级功能覆盖分类改成 47/47，也没有生成“完整协议覆盖率”。

这份报告只证明上述仿真修复与回归，不主张 CPU Core 验证、UVM 回归、FPGA 上板或整个 SPI 模块的形式收敛；形式验证范围和运行状态另见 formal 报告。
