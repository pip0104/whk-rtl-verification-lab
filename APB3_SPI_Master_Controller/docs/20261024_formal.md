# 2026-10-24 SPI 形式验证证据

## 实际范围

对象是同一份仿真使用的 `rtl/apb3_spi_master.sv`，固定 `ADDR_WIDTH=32`、`DATA_WIDTH=32`。只在 FORMAL 编译时于模块内部包含 `formal/spi_properties.svh`；普通仿真与综合不会包含这些检查。没有使用跨层级信号引用替代内部状态。

4 个 prove 任务合计 **18 条 assert**（含辅助不变量），另有 3 条 cover。18 条通过不代表完整模块功能覆盖，也不代表 SPI 总体收敛；没有证明任意 16 位分频、32 位帧在任意软件控制下最终完成。没有 CPU、UVM、riscv-formal、FPGA 上板或 upstream 贡献声明。

| 任务 | 模式 | 数量 | 属性标签与含义 |
|---|---|---:|---|
| reset | prove | 6 | `reset_busy` 忙状态复位；`reset_pins` 引脚复位；`reset_rx` 接收寄存器复位；`reset_count` 计数复位；`apb_ready` 固定无等待；`apb_error` 非法地址错误响应 |
| config | prove | 4 | `config_hold` 连续忙周期配置保持；`reference_hold` 参考分频保持；`config_capture` START 捕获模式；`bits_capture` START 捕获帧长 |
| timing | prove | 6 | `count_bound` 半周期计数不超过 START 分频；`implementation_capture` 实现锁存值等于独立参考值；`edge_due` 应到时必须翻转 SCLK；`edge_clear` 到时计数清零；`edge_not_due` 未到时不翻转；`count_step` 未到时计数加一 |
| rx | prove | 2 | `unread_data_hold` 未读有效数据不被后续完成覆盖；`unread_valid_hold` 没有读 RXDATA 时有效标志保持 |
| cover | cover | 3 | `cover_start` 有效 START 后进入忙；`cover_busy_reprogram` 忙时写不同分频；`cover_finish_after_reprogram` 同帧经历改分频后正常结束，没有 ABORT |

## 环境假设与合法边界

- 第一拍复位且 APB 空闲；之后复位可任意再次发生。异步复位通过 Yosys `async2sync` 归入以 PCLK 采样的形式模型；这不是复位亚稳态或模拟时序验证。
- APB ACCESS 必须有前一拍合法 SETUP；地址、写方向、写数据从 SETUP 保持到 ACCESS；ACCESS 后回到非 ACCESS。复位释放边界也不得直接跳入 ACCESS。
- **未限制 CLKDIV 地址写入时机或数据**，允许忙时增大、减小和写零；未限制 START 模式、1..32 位长度、MISO 数据、非法寄存器地址。
- 配置保持只比较连续 busy 周期；分频边沿检查排除复位与上一拍已 disable 的合法 abort。接收保持也排除复位。没有假设软件永远 enable 来换取伪进度证明。
- `f_start_div` 是独立监视寄存器，只在实际有效 START 捕获可编程寄存器；不是对 DUT 锁存值的 assume。`implementation_capture` 是 assert 辅助归纳不变量。

## 红绿证据

旧 RTL 的 BMC 深度上限 32，在 **step 9** 找到真实合法 APB 反例：`count_bound`、`edge_due`、`edge_clear` 失败。关键过程是 TXDATA 写入、有效 START、忙时 CLKDIV 写入与旧 START 分频不同的值；旧实现继续读取可变的 `clkdiv_reg`，破坏本帧边沿节奏。保留 VCD 与 solver 日志。

修复锁存活动分频后，4 个任务均通过 **k-induction 无界安全证明**；设置中的 `depth 40` 是归纳启动/搜索与基例深度，不是把 prove 降格为仅 40 拍 BMC。cover 深度上限 40，实际 3 个目标分别在 step 6、8、8 达到。完成见证没有通过 abort 或 reset 伪造。
